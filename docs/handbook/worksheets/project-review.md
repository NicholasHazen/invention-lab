# Project review and handover

Project / revision / date / reviewer:

1. What job does the project do, for whom and under what conditions?
2. Which three checks define this revision's finish?
3. Which interface is most likely to fail? Show its contract.
4. Show one prediction and its assumptions.
5. Show the corresponding raw measurement or simulation result.
6. What has been physically tested? What remains hypothetical?
7. What energy or failure consequence limits the next test?
8. What can a new reader reproduce from the files and instructions?
9. What observation would change the current design decision?
10. Continue, revise or stop? Name the next smallest experiment.

## Release inventory

- Purpose, configuration and revision
- Requirements and acceptance results
- Bill of materials with exact identifiers and substitutions
- CAD/source files, manufacturing setup and assembly sequence
- Code environment, commands and expected output
- Raw data, limitations and unresolved questions
- Attribution, reuse terms and private-data check
