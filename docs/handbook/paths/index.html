Let the project set the pace.

Read until you can make a prediction. Run the smallest useful experiment. Record what surprised you. Return to a prerequisite when a missing concept prevents you from explaining the result.

The independent-project chapter supplies briefs for a sensor mount, a bench logger, and a small positioning system.
