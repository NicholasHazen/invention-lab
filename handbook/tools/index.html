01 · Geometry changes the load

Which distance creates the moment?

A point payload acts downward on a rigid arm in the plane of the drawing. The rotation axis points out of the page; the moment arm is the horizontal distance from that axis to the force's line of action. Predict the result at 0°, 45° and 90° before changing the angle.

Weight = 2.45 N · moment arm = 56.6 mm · moment magnitude = 0.139 N·m

F = mg   d = L cos θ   M = Fd   g = 9.81 m/s²

Static model; ignores arm weight, acceleration, friction and deformation. The drawing normalizes arm length for legibility; the force arrow shows direction rather than magnitude. This is a load estimate, not an allowable load or bearing rating.

02 · Dimensions are ranges

Will every allowed pair fit?

Subtract the largest shaft from the smallest hole to find the smallest diametral clearance. A nominal gap can disappear when both parts vary in the unfavorable direction. Enter bounded symmetric dimensional allowances, not a standard deviation.

Diametral clearance

0.07 to 0.33 mm · nominal 0.20 mm

Every pair within these stated dimensional bounds has positive diametral clearance in this ideal circular model.

Hole range
8.10–8.30 mm
Shaft range
7.97–8.03 mm

A positive value alone does not prove a working fit. Shape error, roughness, alignment, temperature, measurement uncertainty and the required clearance still matter. These are assumed bounds until supported by measurement.

cmin = (H − tH) − (S + tS)
cmax = (H + tH) − (S − tS)

Try reducing the nominal hole to 8.05 mm. Which pairs interfere? Then compare a dimensional prediction with a small printed fit coupon.

03 · Smoothing costs response time

What does an RC filter delay?

An ideal resistor charges an ideal capacitor after the input voltage steps from zero to a fixed value. The output is across the capacitor, with no extra load. Increasing R or C smooths changes more strongly and also slows the response.

τ = 0.100 s · cutoff ≈ 1.59 Hz · output at τ ≈ 2.09 V

τ = RC   fc = 1/(2πRC)   Vout(t) = Vin(1 − e−t/τ)

This normalized graph always spans five time constants; read the changing time label. Real component tolerances, source resistance and input loading change the response. This model does not establish ADC compatibility or replace anti-aliasing design.
